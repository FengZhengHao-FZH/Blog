## 通过API Key调用DeepSeek

### 获取DeepSeek的api-key

1. 打开 DeepSeek 官网，进入到[ API Key 的管理页面](https://platform.deepseek.com/api_keys)
2. 点击创建Key后保存
3. 实名认证并充值

### 调用DeepSeek的API

 #### HTTP请求

参考[DeepSeek API文档](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion)，将刚刚创建的Key添加到Authorization请求头中，发起HTTP请求即可。

```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
MediaType mediaType = MediaType.parse("application/json");
RequestBody body = RequestBody.create(mediaType, "{\n  \"messages\": [\n    {\n      \"content\": \"You are a helpful assistant\",\n      \"role\": \"system\"\n    },\n    {\n      \"content\": \"Hi\",\n      \"role\": \"user\"\n    }\n  ],\n  \"model\": \"deepseek-chat\",\n  \"frequency_penalty\": 0,\n  \"max_tokens\": 2048,\n  \"presence_penalty\": 0,\n  \"response_format\": {\n    \"type\": \"text\"\n  },\n  \"stop\": null,\n  \"stream\": false,\n  \"stream_options\": null,\n  \"temperature\": 1,\n  \"top_p\": 1,\n  \"tools\": null,\n  \"tool_choice\": \"none\",\n  \"logprobs\": false,\n  \"top_logprobs\": null\n}");
Request request = new Request.Builder()
  .url("https://api.deepseek.com/chat/completions")
  .method("POST", body)
  .addHeader("Content-Type", "application/json")
  .addHeader("Accept", "application/json")
  .addHeader("Authorization", "Bearer <TOKEN>")
  .build();
Response response = client.newCall(request).execute();
```

#### 使用OpenAI 的兼容模式进行访问

1. 添加OpenAI依赖
   ```xml
   <dependency>
     <groupId>org.springframework.ai</groupId>
     <artifactId>spring-ai-openai-spring-boot-starter</artifactId>
     <version>1.0.0-M5</version>
   </dependency>
   ```
2. 添加YML配置
   ```yaml
   spring:
     ai:
       openai:
         base-url: https://api.deepseek.com  # DeepSeek的OpenAI式端点
         api-key: sk-xxxxxxxxxxxxxxxxxxxxxx  # api-key
         chat.options:
           model: deepseek-reasoner  # 指定DeepSeek的模型名称 deepseek-reasoner or deepseek-chat
   ```
3. 使用OpenAiChatModel类进行调用
   ```
   @RestController
   @RequestMapping("/ai")
   public class AiController {

       @Resource
       private OpenAiChatModel chatModel;

       // 思考完成返回完整结果
       @GetMapping("/chat")
       public String generate(@RequestParam(value = "message", defaultValue = "hello") String message) {
           return this.chatModel.call(message);
       }

       // 流式响应
       @GetMapping("/chatStream")
       public Flux<ChatResponse> generateStream(@RequestParam(value = "message", defaultValue = "hello") String message) {
           Prompt prompt = new Prompt(new UserMessage(message));
           return this.chatModel.stream(prompt);
       }

   }

   ```

## 本地部署

### 下载安装Ollama

进入[Ollama官网](https://ollama.com/)，选择合适版本，点击download进行，下载完成后进行安装。

使用`ollama -v`命令，检查是否安装成功。

### 下载DeepSeek模型

进入[DeepSeek R1模型下载页面](https://ollama.com/library/deepseek-r1)，根据自己的需要，下载合适的版本。

这里以1.5b模型举例，命令行窗口执行`ollama run deepseek-r1:1.5b `，下载DeepSeek模型。

安装完成后，命令行窗口执行`ollama run deepseek-r1:1.5b`即可进行对话。

### 调用DeepSeek的API

#### HTTP请求 OR 使用OpenAI 的兼容模式进行访问

参考上文，和API-KEY方式类似，只是访问路径有差异，默认的路径为http://localhost:11434 ，key随便填一个即可。

#### Ollama兼容API访问

1. 添加依赖
   ```xml
   <dependency>
     <groupId>org.springframework.ai</groupId>
     <artifactId>spring-ai-ollama-spring-boot-starter</artifactId>
     <version>1.0.0-M5</version>
   </dependency>
   ```
2. 添加YML配置
   ```yaml
   spring:
     ai:
       ollama:
         base-url: http://localhost:11434
         api-key: sk-xxxxxxxxxxxxxxxxxxx # 随便填一个
         chat:
           model: deepseek-r1:1.5b  # 与本地模型名称对应
   ```
3. 使用OllamaChatModel类进行调用
   ```java
   @RestController
   @RequestMapping("/ai")
   public class AiController {

       @Resource
       private OllamaChatModel  chatModel;

       private final List<Message> chatHistoryList = new ArrayList<>();

       @PostConstruct
       public void init() {
           chatHistoryList.add(new SystemMessage("You are a helpful assistant."));
       }

       @GetMapping("/chat")
       public ChatResponse test(String message) {
           chatHistoryList.add(new UserMessage(message));
           Prompt prompt = new Prompt(chatHistoryList);
           ChatResponse chatResponse = chatModel.call(prompt);
           if (chatResponse.getResult() != null && chatResponse.getResult().getOutput() != null) {
               chatHistoryList.add(chatResponse.getResult().getOutput());
           }
           return chatResponse;
       }

   }

   ```

###  扩展-可视化界面的使用

本地部署后，为了方便使用，可以搭配可视化界面进行操作。常见的可视化界面有[ChatBox](https://chatboxai.app/zh)和[Cherry Studio](https://cherry-ai.com/)。

二者均有网页版和应用版本，推荐下载应用后，进入设置界面进行模型管理，选择服务提供方为Ollama，添加本地部署的模型进行使用。
